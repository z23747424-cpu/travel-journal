## 这一版改了什么

1. **删除 Tavily 联网搜索**
   - 灵感页的「让精灵找下一站」按钮、联网结果卡片、「选择这里，生成逐日初稿」一并移除；
   - 设置页不再需要 Tavily 密钥，历史保存的搜索密钥会在下次保存设置时自动清除；
   - 推荐统一走「AI 网页版：自己搜索 → 粘贴回复 → 解析」这条路，应用不再发出任何搜索请求。

2. **修复「用它开始写计划」点不动**
   - 原因：只要本机存有未完成草稿，按钮就被禁用且没有任何提示；
   - 现在按钮始终可点，有草稿时会问「继续那份草稿 / 放弃草稿并新建」。

3. **自动填省份**
   - 从推荐卡片新建计划时，会按目的地自动关联省份（含阳朔、婺源、宏村等县级/景区地名）；
   - 手动输入目的地时编辑器也会自动识别；用户手动改过省份后不再覆盖。

4. **字体局部统一**
   - 换用完整中文覆盖的手写字体（Ma Shan Zheng 子集），「陪」「设」等字不再回退成黑体；
   - 设置页「当前主题」、灵感页「AI 网页版推荐」、手账页「照片笔记」等醒目标题统一为手写体；
   - 开源许可弹窗已补充字体授权说明。

## 安装与自查

1. 覆盖安装（若提示签名冲突，先卸载 `cn.edu.traveljournal.dev` 再装）；
2. 设置页底部应显示「旅页 1.7.0」；
3. 灵感页应看不到「让精灵找下一站」；
4. 打开任意计划 → 返回并保留草稿 → 去解析一段 AI 回复 → 点「用它开始写计划」，应弹出草稿对话框；
5. 选「放弃草稿并新建」后，目的地与省份应已填好。
