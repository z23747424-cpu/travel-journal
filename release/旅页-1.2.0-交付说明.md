# 旅页 1.2.0 · 完整中国地图与插画

[源码仓库](https://github.com/z23747424-cpu/travel-journal) · [1.2.0 下载](https://github.com/z23747424-cpu/travel-journal/releases/tag/v1.2.0)。

本地 `旅页-1.2.0.apk`，GitHub 附件 `lvye-1.2.0.apk`，约 17.0 MB，支持 Android 8.0 及以上。测试签名与旧版一致，versionCode 已递增至 3，可用于覆盖更新测试；建议先导出备份。

打开首页就能看到完整中国省级底图，离线可缩放、平移，不再只有缩放按钮和空白背景。“街道底图”是可选联网图层，失败时完整底图继续显示。

选点后可导入自己的 PNG 插画或照片，保存后显示在地图上。插画可拖动调整位置；编辑笔记时可调整大小、换用另一张图片或取消插画显示。点击插画可打开该地笔记，图片、大小和位置会随备份保存。

标记已缩小，全国视野收起文字标签。地点可选“去过／未去过”，去过的足迹点亮对应省级区域，未去过保持暗色，状态也会随备份保存。

53 项测试通过，lint 0 错误/7 项版本提示，APK v2 签名通过，断网地图和亮暗检查通过。预览 `地图预览-1.2.png` 是地图网页组件实测，插画为示例；新版仍待真机验收。

中国边界来自高德/DataV.GeoAtlas 学习交流数据，界面和文档保留来源。本地地理底图不作为旅游推荐名单；联网推荐方式保持不变。
