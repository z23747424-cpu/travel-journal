# 旅页 1.5.0

安装包：`旅页-1.5.0.apk`，约 14.9MB，Android 8.0 及以上。版本号 1.5.0 / versionCode 6，沿用旧版课程测试签名。更新前可在旧版设置中导出备份；保留旧安装包，不必先卸载。

本版将已确认的电脑原型做成原生应用：省份手账地图、照片相册、自定义省份拼贴及想去标记，暖纸手绘主题；灵感中可先请 AI 找目的地、生成初稿，再自己修改旅行计划，也能直接离线手写。

从地图点省份翻相册，长按或点「记一笔」写记录；城市、标题选填。相册的「封面与省份装饰」独立管理颜色、拼贴、封面和标记。旅行计划位于「灵感 → 我的计划」，返回保留草稿，保存后可再改；关联国内省份选填，计划不会自动算作去过。

AI 需要在设置接入自己的 HTTPS 模型服务与 Tavily 搜索密钥，沿用设备加密存储。普通记录与手写计划不要求配置 AI。电脑预览与手机各自保存数据；电脑 JSON 备份不是 Android ZIP。

113 项测试全部通过，Release 构建、lint、签名与 APK 对齐检查通过。暂无手机/模拟器安装运行验收；真实 AI 服务效果需配置后验证。完整证据见 `docs/验证记录-1.5.md`。
