# 旅页 · 省份手账交互原型

按用户确认的「手账＋日记本＋手绘涂鸦」美术稿制作。双击项目根目录 `预览旅页-手账风.cmd`，或运行 `start-preview.ps1`，打开 `http://127.0.0.1:8778/`。

## 可以体验

- 全国只显示真实省界和省名；点击或搜索省份进入相册，支持按钮、滚轮、触屏缩放和平移。全国优先显示主要及有记录的省份标签，放大后展开更多省名；始终没有城市边界或城市标注。
- 省份相册按日期展示照片和文字，可筛选回忆或想去、打开详情、查看完整照片、编辑或删除记录。
- 「记一笔」自动带入当前省份，城市与标题选填；照片或文字至少一项即可保存。离开时保留草稿，再次编辑同一记录会恢复未保存内容。
- 「设计地图」独立保存省份颜色、封面和最多四张拼贴图片；新增手账不重置装饰。原图在本机保留，裁切只用于画面展示。
- 点击地图上的想去标记，选择小旗、定位、星星或爱心，修改颜色和大小，或者上传自己的 PNG/JPG/WebP 图标。也可以在省份相册的「设计地图」中找到入口。标记样式按省份保存。
- 「灵感」分为找下一站、我的计划和想去清单。输入期待，AI 联网推荐有参考来源的目的地；选中后生成逐日草案。也可直接手写计划，无需接入 AI。
- 计划可编辑主题、目的地、日期、预算、备忘和每天的安排；按天及按事项增删、前后移动，收起或返回时暂存草稿。保存后在「我的计划」重开；可删除。国内计划可手动关联省份并插旗，不自动标为去过；海外目的地同样支持。
- 搜索省份、城市、标题、正文和标签；想去记录可以转为已去，沿用同一记录。
- 设置中导出/导入 JSON。兼容旧电脑预览 v1/v2 的记录，已知城市按省归类，不确定归属继续保留在全部手账。旧旅行册和城市装饰作为兼容元数据保留在新导出文件中，未在新版增加这些编辑界面。

## 数据范围

该原型使用新的端口与独立 IndexedDB `lvye-province-scrapbook`，不覆盖旧预览数据库，也不自动读取其他浏览器或手机的内容。若要迁移旧预览，先从旧版导出 JSON，再在新版导入；不是 Android ZIP 备份。

启动入口 `?demo=1` 只在当前浏览器没有记录时载入明确标注的示例。示例照片由 imagegen 生成，不是用户旅行证据。用户修改并保存后的示例不会在「移除未修改的示例」中删除。

图片原始字节保留在浏览器存储和导出文件中，每张支持 JPG/PNG/WebP，最多 25MB。数据库升级到 v2 新增 plans，保留 v1 的 records/designs/settings。JSON v2 备份包含已保存计划及自定义标记，兼容之前的 v1 备份；未保存的编辑草稿和 AI 密钥不导出。

## 使用 AI 旅行规划

在「灵感 → 接入 / 修改 AI」或「设置 → 接入账本精灵」填写公开 HTTPS 的 Chat Completions 兼容服务地址、模型名称、AI API Key 和 Tavily API Key。确认同意发送需求后保存，再点击「让精灵找下一站」。接入信息只放在当前标签页 sessionStorage，关闭标签页后需重新配置。

只有主动生成推荐/行程时才发送当前出游需求、出发地、预算、天数及所选目的地。手账、照片、其他计划不发送。搜索与 AI 服务可能按服务商规则计费。没有配置时进入接入设置，不返回假推荐；可随时手写计划。

本地 Python 服务仅监听 127.0.0.1，专用 `/api/travel` 接口校验同源，先通过 Tavily 查询网页，再让用户模型整理。界面展示参考链接，推荐地必须能在对应检索内容中找到，AI 日程每项带来源；这不代表已经核实实时余票、天气、票价或营业时间。草案和用户修改后的安排均需出发前核对。停止等待会忽略迟到结果，上游已发出的服务请求可能仍会处理。

与同学的 Android AI 模块保持分离；浏览器接口和计划模型见 `docs/旅行计划与地图标记接口.md`，本轮没有修改 Android 源码。

## 素材与许可

- `assets/paper.png`：生成的细纸纹；`decor.png`：带真实 alpha 的柳枝、远山、胶带和银杏叶图集。
- `assets/lake.jpg.png`、`street.jpg.png`：生成的示例旅行照片。
- 图像的完整提示词在 `assets/image-prompts.json`，也嵌入各 PNG 元数据中；批准的视觉参考保留在 `design-previews/scrapbook-v01/`。
- 标题字体为自托管 Ma Shan Zheng 子集，来源、校验见 `assets/font-source.json`，OFL 原文见 `assets/font-OFL.txt`。正文与表单使用系统可读字体。
- 地图来自项目随包行政边界，沿用 `app/src/main/assets/atlas/SOURCES.json` 的来源说明，不使用生成图作为地理数据。

## 本轮验证

完整流程检查与截图位于项目 `.tools/scrapbook-qa/`。使用隔离浏览器上下文，不读取用户日常浏览器记录。已检查 34 省级单元、无市级几何、城市/标题留空保存、照片原始字节往返、同记录草稿恢复、装饰独立、旧数据与旅行册元数据保留、错误文件不写入、搜索，以及手机/窄屏/宽屏。

Browser 插件启动时返回 `failed to write kernel assets` / `os error 3`，改用本机 Chromium / Playwright；页面无外部请求、控制台错误或缺失资源。截图是浏览器原型，不能作为 Android 真机、AI 服务或 APK 验收。

补充检查覆盖空白首页、真实触摸事件选省、键盘关闭、省份搜索、页面标题焦点、编辑器返回保留草稿、草稿对话框恢复、看图返回后再退回全国，以及单省额外 80 条测试记录的相册滚动。结果见 `edge-report.json`，无运行错误。装饰 PNG 的 alpha 已检查，100×100 抽样中透明像素 6608、较不透明绘制像素 1158。

独立收尾审查最初列出的原图、同记录草稿、可访问状态、焦点、颜色对比及手机提示遮挡问题均已修复，定向复核给出 `ship`，范围仅为该修复清单。设计文档已记录实际 tokens 与参考差异；没有将此结论扩大为真机或全局无缺陷保证。
