# 旅页电脑交互预览

双击工程根目录的 `预览旅页.cmd`。脚本自动启动 Ubuntu/WSL 本地服务并打开浏览器，无需下载 APK、连接手机或上传 GitHub。

本轮先在电脑确认交互和排版；预览使用应用随包的同一份真实省/市边界。1.4 已将省份聚焦、周围淡化同步到 Android；旅行册、独立城市装饰、逐图取景等浏览器原型尚未移植，以下功能列表描述电脑预览，不等同于 APK 功能。

- 全国只显示省界与省名；点击省份聚焦，选中省份以浅绿底色和清晰边界突出，周围省份保留淡色轮廓；省内展开城市。不使用整层模糊或遮罩。
- 返回全国、滚轮/按钮缩放、拖动浏览、触屏双指缩放。
- 点击城市打开城市档案：城市封面、照片与旅行册统计、按日期排列的回忆。点击摘要进入完整手账。
- 首页「留下一程」可先选照片、写一句话，再确认城市和日期；长按地图仍可精确选点。标题、标签、所属旅行册和照片排版放在折叠选项中。
- 「装饰这座城」独立设置颜色、最多四张拼贴照片、每张照片的水平/垂直取景和放大倍数、城市封面。新增或编辑笔记不会替换已保存的城市装饰。
- 顶部书本入口打开旅行册；同一册可以收录多座城市的手账，按日期展示时间轴。可以先随手记，之后编辑归册；移除旅行册会保留其所有手账。
- 想去地点可「开始这段旅行」：更新同一条记录为去过，保存出发前的原心愿，不额外生成重复记录。
- 手账有大图叙事、双图并置、当日拼贴三种版式；点击照片可查看不裁切的完整构图。预览图片会在本机缩至最长边 1200 像素，电脑原文件不改动。
- 独立搜索页可以查地点、正文、标签和旅行册名称。
- 预览记录存在当前浏览器 IndexedDB，重开/刷新仍保留；与手机 SQLite 独立。示例有明确标签，可清除。
- 页面自动检查本地文件变更并刷新；编辑卡片打开时推迟刷新，防止打断输入。
- 浏览器中导出/导入的是电脑预览 JSON，不是 Android ZIP 备份，不会自动同步手机。新版 JSON v2 包含记录、旅行册、城市装饰与心愿原文；兼容原 v1 文件。同编号内容覆盖前会提示，非法文件不会改动原数据。
- 数据库由 v1 自动升级至 v2，保留原记录，并从原地图外观初始化独立城市装饰。清除示例会保留用户编辑后的笔记、旅行册和装饰。

服务只监听 `127.0.0.1`，只提供预览文件和边界素材；照片在浏览器内处理，不上传服务器。正常预览不调用 AI，也不下载地图瓦片。

可在终端手动启动：

```bash
python3 desktop-preview/server.py --port 8766
```

访问 `http://127.0.0.1:8766/`。`?demo=1` 仅在当前预览没有记录时载入明确标注的示例。
