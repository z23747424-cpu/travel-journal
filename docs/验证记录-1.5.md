# 旅页 1.5.0 验证记录

日期：2026-11-09。交付范围为原生 Android 应用与本地安装包；本轮未向 GitHub 发布。

## 已进入 Android 的功能

- 首页为随包省级边界的原生 Canvas，始终不渲染市县边界或地名；支持缩放、平移、选省相册和长按记录。城市与标题选填，省份关联明确，旧记录和坐标保留。
- 省份颜色、照片拼贴、相册封面独立于笔记保存；新笔记不覆盖装饰。想去标记可选小旗、定位、星、心及本地图片，自定义颜色和 16–40dp 大小，图片保留透明度与比例。
- 灵感页接入目的地发现、我的计划和想去清单。复用同学修好的真实网页搜索推荐，再生成逐日初稿；可手写、改日期预算和备忘、增删排序、保存、重开或删除，草稿可恢复或确认放弃。
- 计划关联国内省份选填；海外目的地不受中国地图范围限制。计划只贡献想去标记，不自动点亮已去省份。
- 暖纸、墨绿、自托管手写字体和手绘边角已打包；Material3 色彩层级显式采用暖色。照片理解、语义搜索、加密 AI 配置与原有收藏保持。

## 数据与审查

SQLite v2 只新增 plans、plan_draft、province_designs，原有 journals/wishes/draft 表和 JSON 字段保留。ZIP v2 导出已保存内容，包含省份图片与自定义标记；不导出未保存草稿或 AI 密钥。读取 v1 仍受测试保护。导入不会替换现有同 ID 记录，已有省份设计优先保留。

独立源代码审查提出的三项 Important 已修复并定向复核为 resolved：地图仅解码实际需要的图片，拼贴总预算 12MiB、图标 2MiB；本次编辑导入的副本在清空、替换、取消和销毁时清理，持久引用受保护，冷启动清理孤立副本并保护恢复中的照片；计划提交期间冻结修改并串行处理自动草稿保存。

独立视觉收尾结论为 ship，仅限提供的原生软件画布渲染及源码范围，不扩大为设备 UI 验收。设计延续核对见 `Android1.5设计核对.md`。
