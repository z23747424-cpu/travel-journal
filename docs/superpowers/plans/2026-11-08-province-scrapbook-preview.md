# 省级手账风电脑原型实施计划

用户已确认三屏美术稿 v02，授权按该方向制作电脑原型。目标为「省级地图 → 省份相册 → 快速记录」可交互闭环，保留旧预览和旧数据库。

## 实现边界

- 新原型位于 desktop-preview/scrapbook/，独立 loopback 服务与浏览器数据库，不打包 APK、不发布 GitHub。
- 复用真实省级几何和旧城市数据进行导入归类；任何缩放级别不画城市边界和名称。
- 独立保存记录、省份装饰、草稿。保留可选城市、原地点文字和旅行册字段；旧格式导入不改旧数据库。
- 图像为新生成的纸纹、手绘装饰及明确标注的示例照片，正文、地图、表单和按钮用真实 DOM/SVG。
- 保留地图平移/缩放、省份搜索、相册、记录详情、图片查看、快速记录、独立装饰、搜索、JSON 导入导出；灵感页明确连接到现有 Android AI 功能边界，不伪造推荐。

## 步骤

1. 保存美术稿批准状态、表面设计说明；生成纸纹、装饰、两张示例图片，下载许可明确的标题字体。
2. 实现真实省界地图与省份相册，统一手账材质与可读控件；支持宽屏、手机、键盘和减少动画设置。
3. 实现照片或文字即可保存、城市选填、草稿恢复、想去状态、省份装饰、数据迁移和导入导出。
4. 启动本地服务，用隔离浏览器检查完整路径、持久化、照片、装饰、旧格式导入、空状态与手机尺寸，检查无外部请求和控制台错误。
5. 对照批准稿检查截图，集中修复一次发现的问题；独立完成收尾审查与设计文档，打开供用户体验。
