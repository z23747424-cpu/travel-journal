# 灵感计划与自定义地图标记

本轮扩展现有省级手账电脑原型。用户要求：地图想去图标可修改并支持自定义；灵感中由 AI 推荐目的地、生成初版旅行规划，用户再编辑。沿用已确认的纸张、手写标题、鼠尾草绿和省级地图。

实现顺序：
1. IndexedDB 升级到 v2，新增 plans；旧记录、独立省份设计与草稿保留。计划和标记纳入 JSON 备份并校验导入。
2. 小旗可直接点选，编辑四种内置形状、颜色、大小或自己的图片，省份设计独立保存。
3. 灵感分为「找下一站 / 我的计划 / 想去清单」。需求、出发地、天数和预算经搜索与用户配置的 AI 得到候选地，选择后生成逐日草案。无密钥时可以手写计划。
4. 行程编辑支持按天增删和排序、每天事项增删排序、时间/地点/安排编辑、保存、删除和草稿恢复。省份关联选填，仅用户确认后在中国地图插旗；海外目的地同样可规划。
5. 本地 Python 服务提供仅同源可用的专用旅行接口，Tavily 先搜索，兼容 Chat Completions 的用户模型后整理。不设内置目的地库。密钥仅当前标签页会话使用，不导出，不写日志；必须显式勾选同意发送需求。
6. 验证浏览器真实交互、旧版数据库迁移、备份、标记、计划、草稿和模拟上游的 AI 流程。真实模型调用需要使用者填入配置，不能将模拟测试描述为真实推理验证。

本轮不修改同学 Android AI 源码，不构建 APK，不发布 GitHub。新增 API 和数据模型记录供 Android 对接。
