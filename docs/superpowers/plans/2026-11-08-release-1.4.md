# 旅页 1.4 发布实施计划

用户已授权合并 AI 修复、地图修复、美术优化并发布 GitHub。沿用已确认的米白苔绿杂志风与省份聚焦交互，直接在发布分支执行。

## 交付标准

- 版本 1.4.0、versionCode 5、包名不变，与已有 1.3 APK 使用同一证书。
- 只合并同学真正修改的 WebTravel.kt、DiscoverScreens.kt、WebTravelTest.kt；原始交付目录不改动。
- 空结果重试使用不同的精简搜索词，最多三次，保持取消与来源校验。
- Android 全国显示省份，点击省份放大，选中板块突出，周围淡化；省内展开城市，城市颜色/照片与想去旗保留。
- Lucide 细线图标统一导航和地图工具，优化标题、留白、图例、手账卡片与空状态；不依赖在线图片或额外生图模型。
- 完成 Android 单元/原生绘图测试、lint、APK 构建与签名验证；能启动设备时完成真实界面和升级检查，不能时如实记录边界。
- 发布 GitHub v1.4.0，包含可安装 APK、源码 ZIP、SHA256 和本次验证记录。

## 执行步骤

1. 比较 AI 文件并整合；添加精简查询、重试次数、取消等回归测试。
2. CityAtlas.kt 保留省份元数据；NativeTravelMapView.kt 增加聚焦与淡化，MapSurface.kt/MapScreens.kt 接入状态与导航。添加省份命中、全国返回与绘图回归检查。
3. 复制必要的已核验 Lucide 资源和许可，更新 Ui.kt/MainActivity.kt/JournalScreens.kt 的层级与图标，保持记录/备份格式兼容。
4. 运行 scripts/build.sh 的单测、lint、debug/release 与 AndroidTest 构建任务；若出现错误先定位再修复。
5. 使用已有本机签名，检查证书与 1.3 一致；核验 APK 版本、资源与 SHA256，更新交付文档。
6. 检查远端当前状态，快进整合到默认分支，推送发布分支与默认分支后发布 Release；不覆盖旧标签或旧安装包。
