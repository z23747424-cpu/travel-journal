# 第二轮：从地图开始的旅行手账

用户要求中国地图作为首页，点击任意位置创建笔记，点击已有笔记的地点进入笔记；进一步选择可缩放到街道的真实地图，并明确推荐必须使用联网搜索，不使用内置目的地范围。

## 交互

- 首页以真实地图为主，默认中国视野，可自由缩放、平移到世界各地。点击空白地点后命名并开始编辑，保存后在原经纬度出现笔记标记。
- 同一位置一篇笔记直接打开，多篇则显示该地点的笔记列表并支持继续新增。缩小时邻近标记聚合，放大后展开。
- 保留独立搜索、灵感、设置；首页提供全部手账、未标位置记录、草稿入口。编辑页可补选、更改或移除地图位置。旧记录不会被猜测为真实去过某个坐标。
- 纸色、绿色与暖棕标记沿用杂志主题，地图承担首页主体。笔记列表、照片与文字仍用于具体记录的阅读。

## 地图与持久化

Compose 承载系统 WebView 中的本地 Leaflet 1.9.4；仅底图瓦片联网，笔记文本不发送给地图服务。使用 HTTPS 虚拟本地资源、严格资源白名单、内容安全策略与最小 JS 桥，外部链接交给系统浏览器。OpenStreetMap 署名始终可见，正常 HTTP 缓存，不提供批量下载或离线地图。

Journal 增加可空经纬度，必须同时为空或同时为有效数值。SQLite 原有 JSON 行保持兼容，草稿、备份与导入保留位置；无位置的 1.0 备份仍可导入。展示坐标为 WGS84，不获取设备 GPS 权限。示例的坐标明确为教学演示，不能当作用户足迹。

## 联网推荐

移除运行时内置目的地文件。通过用户配置的 Tavily 搜索密钥实际检索网页，已有 AI 服务整理返回资料和需求；搜索结果中的来源 ID 决定可引用链接，模型不得凭空产生来源。结果可收藏，与既有想去清单兼容。缺少搜索配置、无结果、网络错误都明确显示，不用本地目录冒充联网结果。普通模型接入不被描述为自动拥有联网能力。搜索密钥同样经 Android Keystore 加密，备份排除密钥。初版目的地数据迁入实验目录，保留原冻结基线作为历史课程材料。

## 验证与交付

新增位置序列化、旧数据兼容、坐标验证、地点聚合载荷、联网结果来源约束与取消测试。浏览器离线夹具检查真实地图引擎的点选、缩放与标记交互，不通过机器人拖动访问公共瓦片。执行 Gradle 编译、单元测试、lint 与设备测试代码编译。新 APK 版本 1.1.0，保留 1.0 文件与 GitHub 版本；没有手机/模拟器时仍明确真实设备未验收。
