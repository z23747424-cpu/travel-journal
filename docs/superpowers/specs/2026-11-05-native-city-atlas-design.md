# 原生城市旅行拼贴地图

用户于 2026-11-05 明确选择本设计并要求直接制作。此设计替代 1.2 的省级亮暗底图。地图由用户负责，AI 由协作同学负责。

## 用户体验

- 首页大幅地图为视觉主体，纸色背景；未去城市只有浅色细线/虚线边界，不填暗色。
- 按城市点亮：杭州足迹只填杭州图块；同省其他城市保持轮廓。直辖市作为一个城市，省直辖单位保留数据中的独立边界。
- 已去城市可用柔和预设色、自定义 #RRGGBB，或将城市中手账照片裁剪成图块内的拼贴。
- 未去/准备去的地点用小旗子，不填已去图块，不计已去统计。
- 长按空白地图选择真实位置，底部卡片填写地点、去过状态和城市样式，开始写手账；也可直接保存想去旗。
- 点击已有地点先显示照片和文字摘要，再进入完整手账；同城多篇可以选择。
- 双指缩放、拖动浏览、双击放大、缩放按钮和全国复位。全国少文字、密集地点聚合；放大展开地点和城市名。
- 个人插画保留、可长按拖动；图片区分地图图块拼贴与原有地点贴纸。
- 城市列表提供非手势入口，支持按名称找城市，屏幕阅读器可从列表选城和查看已有笔记。

## 技术方案

用 Android 原生 View/Canvas 绘制本地矢量路径，Compose 提供页头、按钮和底部卡片。不启动 WebView，不接入地图 SDK，不请求地图瓦片，不需要地图 Key。1.2 网页资源保留供历史比较，但不作为新版地图运行入口。

行政边界是素材而非在线地图服务。沿用课程允许的 DataV.GeoAtlas 边界来源并记录高德来源/学习用途；下载市级文件后生成简化的随包素材。台湾县市使用明确授权的 NLSC 开放数据衍生 GeoJSON，固定版本、校验值及来源入清单。保留完整省级外形和南海图形，不捏造城市边界。若某份数据缺失，构建脚本报错，不默默用省份冒充城市。

数据层负责解析多面、多环、孔洞、坐标投影、城市包含判断和标记聚合。渲染层缓存 Path 与缩略图；触摸仅改变视野或产生选择回调。照片解码与素材读取放在 IO 线程，解码失败回退已选纯色。原生控件实测非零尺寸和真实绘制像素。

## 数据和协作接口

Journal 增加有默认值的 mapCityCode、mapFillColor、mapFillMode（color/photos）。坐标仍是实际经纬度，城市代码辅助编辑；绘制以位置包含判断为准，避免拖动后点亮原城市。同城采用最近更新的已去记录决定填色样式，拼贴汇总该城市已去手账的本地照片，最多四张。

旧数据默认柔和绿色、纯色填充，保留原 visited 语义。新字段进入 JSON 和备份；照片继续引用 Journal.photos，导入时沿用现有文件名重映射。地图不改 AiClient、WebTravel、Search 或推荐协议。共享 Models 和 MainActivity 仅添加可选字段及地图保存回调，在协作文档说明。

## 验收和边界

测试杭州包含、杭州点亮而浙江其他城市不亮、未去旗不填城、自定义色及照片裁剪、旧记录兼容、备份恢复、实际 Canvas 非空、缩放和触摸坐标互逆。运行 Android 编译、单元测试、lint、设备测试代码编译。

原故障当前仅在人工“地图容器高为零”实验中复现相同外观，未在手机读取尺寸，不能宣称原 WebView 根因已确认。没有设备时，原生绘制截图明确为 Robolectric Canvas 渲染证据，不称真机或模拟器整机验收。新 APK 使用相同签名和递增版本，保留原安装包。
