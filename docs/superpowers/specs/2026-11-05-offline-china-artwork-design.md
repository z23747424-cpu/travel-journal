# 完整中国地图与个人插画足迹

用户反馈：有缩放按钮但地图背景空白；要求直接显示完整中国地图、可缩放，并让用户自己设计游玩地点和插入插画。

## 故障与改法

1.1 仅依赖在线瓦片，没有可独立显示的完整地理底图。新增的断网回归检查在旧版实际失败：找不到省级地图图形。1.2 默认加载随 APK 保存的中国 GeoJSON，绘制 34 个省级区域及原始南海相关图形，启动和缩放都不请求外部底图。街道瓦片改为用户主动切换，失败时完整底图继续可见。保留地图选点与已存笔记逻辑。

中国边界来自 DataV.GeoAtlas 的高德学习交流数据，标注来源与使用范围；不自行杜撰轮廓，不将地理底图变成推荐地点名单。已有联网推荐流程不变。

## 插画交互

- 地图任意选点后可导入个人插画或照片，创建一篇带该位置和图片的笔记；正文可稍后补充。
- 编辑页可指定哪张图片显示为地图插画，并调整大小；可取消插画显示而保留笔记照片。
- 插画常驻在地理位置上，可拖动调整位置，结束时保存坐标；点击打开该地笔记。同地点多篇仍可展开列表。
- 插画为原图的本机缩略副本，保留透明通道和正确方向，不把图片上传地图服务。只允许本机受控照片路径进入地图页面。

后续用户明确要求标记缩小，并用亮暗表示是否去过：新增可编辑 visited 标志；去过足迹落入的省级区域提亮，其他区域暗色。默认插画和普通标记缩小，全国视野收起插画标签，保留触控区域；教学示例不默认点亮实际足迹。计划不会被 AI 回顾当成已发生经历。

## 数据与验证

Journal 增加可空 mapSticker（必须在 photos 中）及 mapStickerSize，旧 JSON 使用安全默认值。备份恢复需要同步重映射插画文件名，拖动操作同步防止重新创建已删除记录。

Android 资源测试直接验证本地 HTTPS 资源路由能读取中国地图文件和透明缩略图。浏览器完全阻断外部请求，检查真实地理图形、缩放、插画和拖动，不能再用纯色瓦片代替地图显示验证。版本升至 1.2.0，保留 1.0/1.1 文件与标签；物理设备和真实服务状态继续单独说明。
