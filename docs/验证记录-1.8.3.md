# 验证记录 · 旅页 1.8.3

日期：2026-11-13　版本：`1.8.3 / versionCode 14`（上一版 1.8.2 / 13）
本轮改两件事：**进省判定改成界面正中的固定十字架**、**小省份放大到最大倍数立即进省**。

## 用户反馈

> 全国地图中间加个固定的十字架，十字架在哪个省就进哪个省。现在放大总是进四川，重庆进不去。
> 上海、北京这种小省，放大到最大也进不去的话，到最大倍数就直接进。

## 根因

`ProvinceMapView` 原来用**两指中点**判定进省（`zoomAt(factor,focusX,focusY)` 里的 `provinceAtScreen(focusX,focusY)`，`zoomBy` 才兜底用屏幕中心）。这带来两个问题：

1. **捏合中点常常落在隔壁省**。重庆是个环形/多块轮廓，两指围绕重庆捏合时中点很容易压进四川；而四川 `threshold=(fitZoom*0.62)≈3.41`，重庆 `≈7.79`——四川阈值不到重庆的一半，于是在放大到 3.4 倍那一刻就先被四川抢走，用户再也看不到重庆进省。
2. **小省份根本没有可达的阈值**。阈值公式 `fitZoom(target)*0.62` 被 `coerceIn(1.6f,maxZoom=9f)` 钳住：

   | 省 | fitZoom（1080×2160@3x 实测） | 理论阈值 | 钳后 |
   |---|---|---|---|
   | 上海 | 18.26 | 11.3 | 9（不可达） |
   | 北京 | 29.49 | 18.3 | 9（不可达） |
   | 重庆 | 12.56 | 7.79 | 7.79 |
   | 浙江 | 12.81 | 7.94 | 7.94 |
   | 山东 | 7.80 | 4.84 | 4.84 |

   上海、北京、天津、港澳的阈值 > 9，而 `zoom` 最大就是 9，`zoom>=threshold` 永远不成立；更糟的是 `zoom` 已到 9 时再捏合，`zoom==old` 直接 `return`，连判定都不执行。

## 方案

### 1. 判定点：两指中点 → 固定十字架（主改）

`ProvinceMapView`：
- `internal fun crosshairProvince()`＝`provinceAtScreen(width/2f,height/2f)`，「视图正中央压着的省」是唯一目标；
- `internal fun drillAtCrosshair()`：全国层才进省，`zoom>=drillThreshold(target)` 或「到顶兜底」满足即 `onDrillProvince(code)`；
- `zoomAt` 末尾不再看 `focusX/focusY`，一律 `drillAtCrosshair()`；
- **捏合手势也改成以十字架为锚**：`ScaleGestureDetector.onScale` 从 `zoomAt(scale,d.focusX,d.focusY)` 改成 `zoomAt(scale,width/2f,height/2f)`。这样两指缩放时十字架下的地理点始终不动，瞄准了重庆就不会在放大过程中被拖到四川——判定与视觉完全一致。

`drillThreshold(province)` 去掉了 `maxZoom` 上限钳制（只保留 `coerceAtLeast(1.6f)`），否则小省的「真实阈值」被抹平，无法区分大小省。

### 2. 小省：到最大倍数立即进省

- `zoomAt` 里 `zoom==old`（已顶到 9 倍）且在全国层继续放大时，**先** `drillAtCrosshair()` 再 `return`——解决「已经在 9 倍，再捏一下什么都不发生」；
- `drillAtCrosshair()` 增加 `enterProvinceAtMaxZoom && zoom>=maxZoom-.001f` 分支：到顶就按十字架进省；
- 开关 `var enterProvinceAtMaxZoom=true` 默认开启（不改默认体验），并在设置页给出入口：**设置 → 地图 → 放大到最大直接进省**，关掉后小省不再被放大带进去，仍可在全国层点开。持久化 key 为 `mapEnterAtMaxZoom`（`JournalRepository.enterProvinceAtMaxZoom()/saveEnterProvinceAtMaxZoom()`，默认 `true`），`MainActivity` 启动时读取、开关写回。

### 3. 十字架本体

`ProvinceHome.kt` 新增 `MapCrosshair`：48.dp 画布、`gap=10.dp`、`len=20.dp`，白色半透明粗底（α153、1.2.dp×2.8）保证在浅色省界上也看得见，上面压 1.dp、α140 的墨色细线，圆头收笔。叠在地图 `AndroidView` 之上、只在 `focus==null`（全国层）显示，`Alignment.Center` 对齐，与 `ProvinceMapView` 的 `width/2,height/2` 严格重合。

### 4. 未改动

`countyMinZoom=.6f`、`returnZoom=.68f`、`drillFillRatio=.62f`、`focusProvince` setter 的等比换算与钳制、1.8.2 的区县未加载兜底与 0.2 秒淡出、`NativeTravelMapView` 全部保持原样。

## 遗留 / 可继续做

- 十字架下正好压着省名标签时，标签会被白底笔画压住一点（实测可读）。若用户嫌乱，可把标签在「被十字架覆盖」时上移 6.dp。
- 设置页开关是新增的，若用户希望「永远固定规则」，把 `enterProvinceAtMaxZoom` 默认值写死并隐藏该行即可。
