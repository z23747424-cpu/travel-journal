## 一、为什么"改了代码，装到手机上却没变化"

时间线还原（同一台机器上的文件时间戳）：

| 时间 | 事件 |
|---|---|
| 11-12 09:14 | 新增 `AiWebHelper.kt` |
| 11-12 09:45 | 把「AI 网页版推荐」UI 加进了 `DiscoverScreens.kt` 的 `InspirationScreen` |
| 11-12 10:48 | 构建出 v1.6.0 APK，**装到手机上的就是这一版** |
| 11-12 15:21 | 才把同一套 UI 补进 `NativeInspirationScreen.kt`（真正在用的灵感页） |
| 11-12 15:45 | 重新构建，此时 APK 里才有新功能 |

根因：**改的是死代码**。`MainActivity` 的 `tab==2` 调用的是 `NativeInspirationScreen`，而 `DiscoverScreens.kt` 里的
`InspirationScreen` 从 v1.6 起已经没有任何调用方。在 10:48 那一版里，AI 网页版面板只存在于这份死代码中，
编译能通过、dex 里也有字符串，但界面上永远不会出现——这就是"安装了新版却毫无变化"。

验证方式：解包 APK 的 `classes*.dex` 搜索界面字符串；10:48 直接不可见，而本次构建的 `classes3.dex` 中
可检索到 `从剪贴板读取`、`用它开始写计划`、`网页版推荐`。

## 二、本次改动

### 1. 删除重复实现（消除复发可能）
- `DiscoverScreens.kt`：删除旧 `InspirationScreen` 及其私有组件，只保留仍在使用的 `SearchScreen`，
  并在文件头写明"灵感页功能只写在 `NativeInspirationScreen.kt`"。

### 2. `AiWebHelper.kt` 重写解析，容忍真实 AI 输出
- 支持前后夹带说明文字、` ```json ` 代码围栏、BOM、纯数组回复（`[{...}]`）。
- 括号配对改成字符串感知扫描，避免 JSON 字符串里的 `}` 提前截断。
- 字段名兼容中英文：`name/place/名称/地点`、`reason/推荐理由`、`caution/注意事项`、`sourceUrl/来源` 等。
- 来源网址归一化：优先抽取 `http(s)://…`，裸域名补 `https://`，丢弃 `javascript:`/`mailto:` 等非 http(s)。
- 去重（同名、同 ID）、跳过空名称、上限 8 条。
- 错误信息改为可操作提示（缺 `destinations`、不是 JSON、括号不完整各有不同文案）。
- 提示词明确要求"资料不足可返回空列表、不要编造网址"。
- 新增 `clipboardText()`、`services`/`serviceLabel()` 多 AI 服务支持。

### 3. `NativeInspirationScreen.kt` 面板重做
- 四个 AI 网页可选：Kimi / 豆包 / 通义 / ChatGPT（原来是写死 Kimi）。
- 「从剪贴板读取」一键取回回复，并用 `isAiResponse()` 预判是否为 AI 回复。
- 解析失败就地显示在面板里，不再复用顶部全局错误（原先会附带误导的"检查 AI 设置"）。
- 状态改用 `rememberSaveable`，旋屏/切页后输入与结果都还在（结果由保存的原文重新解析得出）。
- 结果卡片新增：地区与建议停留天数、`注意：…` 单独一行、已收藏时按钮变「已收藏」、
  以及「用它开始写计划」——不调用 AI，直接用该地点预填 `TravelPlan` 打开行程编辑器。

### 4. 版本与可见性
- `versionCode 7 → 8`，`versionName 1.6.0 → 1.6.1`。
- 设置页底部版本号改为读取真实 `versionName`（原先写死为 "旅页 1.5.0"），
  装完可在设置页直接确认是否为 1.6.1。

### 5. 测试
- 新增 `app/src/test/java/cn/edu/traveljournal/AiWebTest.kt`（12 例）：代码围栏+寒暄、中文键名、纯数组、
  缺字段、空列表、去重、排除名单、非法 URL、URL 归一化、空名称、剪贴板判定、提示词内容。
- 修正 `ActivitySmokeTest` 的包名断言：开发版带 `.dev` 后缀，改为前缀匹配（否则每次 debug 构建必红）。

## 四、安装说明

1. 如果手机上已有 `cn.edu.traveljournal.dev`（老 v1.6.0 debug 包），可直接覆盖安装；
   若提示"应用未安装/签名冲突"，先卸载旧包再装。
2. 打开应用 → 底部「灵感」→ 第一个页签「找下一站」→ 在上方输入需求 →
   点「用 AI 网页版推荐（免费，无需 API）」。
3. 设置页最下方应显示「旅页 1.6.1」；若仍显示旧版本号，说明装的还是旧包。
