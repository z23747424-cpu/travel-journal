# 先看电脑预览，再做 Android

用户于 2026-11-07 确认后续流程：先在电脑上查看交互与排版，满意后再生成 Android 安装包。普通预览迭代不要求下载 APK，不自动上传 GitHub，也不自动发布 Release。

## 本轮设计

全国视图只显示省界和省名，点击省份后自动放大该省，周围省份淡化模糊；选中省内清晰显示市级图块。可以返回全国、滚轮/按钮缩放、拖动和长按选点，继续体验城市填色、照片拼贴、想去旗帜、笔记预览与搜索。

全国省名自动避让，必要时加细引线；透明标签点击范围重叠时匹配最近标签，避免点浙江却进入江西。城市文字与小旗的触控区域重叠时，按实际文字与标记的距离判断，避免附近的小旗抢走城市点击。

城市记录的本轮扩展见 [城市档案与旅行册](电脑预览-城市档案与旅行册.md)：城市封面与地图装饰独立保存；首页照片快记；多城市旅行册时间轴；照片版式与完整构图查看；想去转足迹保留原心愿。

## 在本机打开

- 双击工程中的 `预览旅页.cmd`；原工作目录 `E:/机器学习实验作业/预览旅页.cmd` 也有启动入口。
- 启动器自动运行 Ubuntu/WSL 的本地服务并打开浏览器。当前地址通常为 `http://127.0.0.1:8766/`，被占用时自动选用 8767～8776。
- 可切换手机/平板预览。没有记录时，启动链接可载入明确标注的示例；也可清除示例，换成自己的照片和文字。
- 修改 `desktop-preview/preview.js`、`preview.css`、`journal.js` 或 `journal.css` 后，页面自动刷新；编辑卡片打开时推迟刷新，保留输入时间。

## 数据及验证范围

使用 Android 随包的同一份真实边界素材，当前共 34 个省级区域、391 个城市及独立行政单元。电脑交互使用 SVG，与 Android 的 Canvas 渲染方式不同；当前预览不代表 Android 运行验证。用户确认后再将省份层级和聚焦行为同步到原生绘制，并执行 Android 检查。

记录和图片仅在当前浏览器的 IndexedDB 内保存，与手机数据独立。导出 JSON 也是电脑预览格式，不是 Android ZIP 备份。编辑示例后会将该记录转为个人预览记录，清除示例不会将它删除。

浏览器交互检查已通过：省份点击、周边模糊、返回全国、照片导入、自定义色、保存与重开、本地搜索、长按选点、滚轮缩放、拖动、手机/平板布局、窄屏无横向溢出，以及修改本地文件后自动刷新保留记录。检查没有请求外部地图服务，控制台未出现脚本错误。

测试脚本 `scripts/test-desktop-preview.cjs` 与 `scripts/test-desktop-journal.cjs` 使用现有 Playwright；输出在 `.tools/desktop-preview-qa/`。这些是浏览器预览证据，不称手机或模拟器截图。本轮不改动 Android Kotlin 文件、不递增 APK 版本、不发布远端更新。
