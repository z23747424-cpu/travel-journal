# 1.2 完整中国地图与个人插画验证

日期：2026-11-05。用户反馈旧版能看到缩放按钮，但底图空白。本轮改为中国完整地理底图随 APK 保存，并加入自定义插画、大小与拖动保存。

## 复现与修复

旧版只使用外部瓦片，没有本地完整地图图形。新增的断网回归检查先在旧代码上实际失败：未找到省级区域图形。用户网络中瓦片不可用的具体原因未取得日志；修复使默认底图不再依赖该外部服务。

1.2 默认直接绘制本地 GeoJSON 的 34 个省级区域及原始南海图形，包含台湾、海南、港澳。缩放和平移不触发外部地图请求。只有点击“街道底图”才请求街道瓦片，失败时完整底图保留。首次升级使用新的视野状态键，避免沿用旧版空白视野。

插画由用户自行导入，可调大小、拖位置并点击看笔记。图片作为笔记的本机照片保留；地图读取小尺寸 PNG 副本，保留透明通道并纠正方向。备份恢复同步重映射图片文件名，拖动是同步仓库操作，不能重建已删记录。

按用户继续反馈缩小标记：默认插画 32，全国视野限制尺寸并收起标签，触控区域保留至少 48。去过／未去过由用户切换，省级区域根据去过足迹的多边形包含关系提亮；无去过足迹时保持暗色。教学示例和新计划不默认计为去过。

## 浏览器检查

`scripts/test-map-offline.cjs` 在 390×520 和 1024×650 视口通过：实际绘制 34 个省级地图路径、显示插画、点击、拖动和缩放；默认和缩放阶段外部请求为 **0**。街道图层请求通过测试路由全部阻断后，地图仍保留并显示失败提示。最终测试使用统一请求拦截，外部请求不会发送至公共地图服务。

`scripts/test-map.cjs` 原有选点、多篇列表、全球坐标、文本安全与失败恢复检查也通过。截图使用真实随包地理数据；插画是测试脚本绘制的示例。预览在 `release/地图预览-1.2.png`，是网页组件截图，手机整体界面仍待实机验证。

最后一轮浏览器检查额外验证：全国视野插画不超过 32；去过杭州会点亮浙江，未去过的大理不会点亮云南，将杭州改回未去过后浙江恢复暗色。最终截图同时展示亮暗状态与小标记。
