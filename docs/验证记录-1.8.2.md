# 验证记录 · 旅页 1.8.2

日期：2026-11-13　版本：`1.8.2 / versionCode 13`（上一版 1.8.1 / 12）

本轮只修一条：**全国地图切进省地图时，中间会闪几帧「缩小版全国地图」。**

## 用户反馈

> 功能基本实现，但在全国地图切换到省地图时，中间有那么几帧（录视频慢放发现）出现了全国地图的缩小版。可以让地图切换更流畅吗，及避免切换时出现的缩小版全国地图。

## 根因

`ProvinceHome` 的区县数据是**异步**读的（`LaunchedEffect(focus)` → `CountyAtlas.units()`）。`focus` 变化的那一帧：

1. `AndroidView.update` 先把 `v.focusProvince = focus`，setter 立刻把 `zoom` 从「全国比例尺」换算成「省比例尺」，`fitZoom(浙江)≈30` → `1/30≈0.033`，被 `countyMinZoom=0.6` 兜住，得到 `zoom=0.6`（这个 0.6 是有意的：进入瞬间省占屏≈60%，与下钻阈值 62% 连续）；
2. 但同一帧 `counties` 还是空，`areas()` 在 `countyView==false` 时回落成**全国省列表**；
3. `transform()` 用 `boundsOf(areas())` 定比例尺 → **全国 bounds × zoom 0.6 = 一张缩到 60% 的全国地图**。

区县数据平均晚 1–3 帧到位（322 KB JSON + 解析），正好是用户慢放看到的「几帧缩小版全国图」。进出两个方向都受此影响。

## 修复

### 1. 数据未到位时只画本省（主修）

`ProvinceMapView.areas()`：`focusProvince != null && counties.isEmpty()` 时返回**该省单条 Area**（取 `atlas.provinceAreas` 里的 shortName/center/shape），取不到才回落全国。

比例尺天然连续：设全国 fit 为 `N`、省 fit 为 `F`、下钻时 `zoom = z`、下钻后 `zoom = z·N/F`；
- 切换前：`scale = N·z`
- 兜底帧：`scale = F·(z·N/F) = N·z` —— **完全相同**，所以不是「变小了再弹回来」，而是同一张省轮廓原地替换成区县。

### 2. 区县为空时不再把整省当成「已进入的区县层」

`countyView` 仍是 `focusProvince!=null && counties.isNotEmpty()`（表示「有区县数据」），所以兜底帧继续按省图层的规则上色/打标签：不会先把整省涂成已访问亮色再跳成区县分色，也不需要额外拆语义。已验证 `visitedCodes/markedCodes/labelVisible` 走省分支正是兜底帧想要的效果。

### 3. 切换省时先清空上一层的区县

`ProvinceHome`：`LaunchedEffect(focus)` 开头 `countyUnits = emptyList()`。否则「省 A → 全国 → 省 B」的快速往返里，B 加载期间会拿 A 的区县去套 B 的比例尺（比中间帧更错）。

### 4. 进出层级加 0.2 秒淡出（体验）

`ProvinceMapView`：`focusProvince` 变化时把**上一帧**画进一张半分辨率位图（`snapshotFrame()`），`onDraw` 把它按剩余时间从 100% 透明度淡到 0（`fadeMs=200`），`postInvalidateOnAnimation()` 驱动，不依赖 Compose 动画，也不拦截触摸。
- 只在 `isAttachedToWindow` 时生效 → Robolectric 里不启用，测试仍然逐像素确定；
- 位图半分辨率（1080×2400 → 540×1200，约 2.2 MB）并在结束时 `recycle()`，`onDetachedFromWindow` 也回收；
- `RectF` 预分配，避免 `DrawAllocation` 告警。
