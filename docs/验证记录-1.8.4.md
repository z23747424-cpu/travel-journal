# 验证记录 · 旅页 1.8.4

日期：2026-11-16　版本：`1.8.4 / versionCode 15`（上一版 1.8.3 / 14）
本轮只修一件事：**放大进省后，视角被弹回全国、十字架落到四川，于是进了四川。**

## 用户反馈

> 放大某个省，最后进的是四川。缩放级别看着没变，视角突然就跳到四川，十字架也在四川。

## 复现（逐帧日志，1080×1620@3x，十字架先对准浙江）

```
330000 浙江 起点十字架=330000 阈值=7.94253
  >>> DRILL(330000) 十字架=330000
  第 105 步进省
  <<< LEAVE 十字架=330000
   +1 层=全国 十字架=510000
  >>> DRILL(510000) 十字架=510000
   +2 层=510000 …
```

进省是**对的**，问题出在进省的下一帧：省图层立刻判成“缩回全国”，而退出时相机复位到全国默认中心（≈104.06, 30.67，成都附近），十字架随之落到四川，同一根手指顺势把四川也进了。34 省粗扫里只有内蒙古（贴着全国外包框中心）看起来正常，其余全部中招——所以“只有部分省份进四川”其实是“偏远省份必中、中心省份看不出来”。

## 根因（三处叠加，缺一不成）

1. **进省倍数正好压在退出线上。** 进省那一刻 `zoom=drillThreshold=fitZoom×0.62`，换算到省图层是 `0.62`，而省图层“继续缩小就退出”的阈值 `returnZoom=0.68`。于是下一帧手指哪怕还在放大，`zoom` 仍 ≤0.68，直接 `leaveProvince()`。
2. **退出时相机复位到默认中心。** `focusProvince=null` 时 `panX=panY=0`，全国层视角回到外包框正中；那个点在成都附近，四川又贴近全国几何中心，于是十字架“总是”掉进四川。
3. **同一根手指可以连续切换层级。** 退出后 `zoom` 换算回全国层仍 ≥ 进省阈值，同一次捏合里第二次 `DRILL` 立刻发生——用户看到的就是“级别没变、视角跳到四川、然后进了四川”。

顺带发现并修掉一个相关缺陷：`zoomAt` 里 `zoom≤1.01f` 的归位逻辑对放大方向也生效，慢慢捏时每帧 0.3% 的增量会被反复抹掉，地图卡死在 1 倍不动。

## 修法（`ProvinceMapView.kt`，四处）

| # | 位置 | 改动 |
|---|---|---|
| 1 | `focusProvince` setter | 进省倍数改为 `(zoom/after).coerceAtLeast(0.95)`：进省后省铺满九成半屏幕，离 0.68 的退出线留足余量，不再“一进就站在出口” |
| 2 | `focusProvince` setter | 退回全国时不再把 `pan` 归零，而是把**刚才那个省的中心**重新放回十字架下：视角不甩回全国正中，十字架不会落到四川 |
| 3 | `onScaleBegin/onScaleEnd`、`drillAtCrosshair()`、`leaveProvince()` | 手势开始时锁定十字架下的省 `lockedProvince`；一次捏合里最多切换一次层级（`levelChangedInGesture`），进省目标只认锁定的省 |
| 4 | `zoomAt` | `zoom≤1.01f` 归位只在 `factor<1f`（确实在缩小）时生效，慢捏不再卡在 1 倍 |

按钮路径（`zoomBy`/"全国"键）不受手势状态影响，行为与 1.8.3 一致。

## 回归测试

新增 `ProvinceDrillTransitionTest`（5 条，全部通过）：

- `slowPinchStaysInTheProvinceItEntered`：北京/天津/河北/内蒙古/浙江/云南/广西，一帧 1.02 的慢捏合进省，断言**只有一次 `进:<本省>`、没有 `退`**，进省后继续捏 5 帧仍不换层。

原有 `ProvinceDrillTest` 7 条全部保留并通过。
