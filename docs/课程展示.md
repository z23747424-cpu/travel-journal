# 旅页课程展示说明

项目题目建议：基于预训练多模态模型的智能旅行手账 Android 应用。

## 展示顺序

1. 打开“地图”，直接查看完整中国省级底图。断网时演示缩放与平移，底图仍然显示；需要街道细节时再主动切换联网图层。可主动载入教学示例，示例不是用户旅行证据。
2. 点击地点，可写笔记或导入自己的插画、照片。保存后在地图显示插画，拖动调整位置；编辑时可调整大小。点击标记查看同地笔记。原有笔记可补充位置并选一张图片作为地图插画。
3. 在独立“搜索”页输入“看海”等文字，展示本地关键词搜索。配置 AI 后可展示使用不同说法寻找同一段经历的智能搜索。
4. 先在设置填写个人 AI 服务和 Tavily 搜索密钥，再在“灵感”输入需求，例如“想看海、节奏慢一点，两三天”。应用实际搜索网页，再请模型整理候选、来源与待核对条件。没有预置目的地范围，也不限定国内。可收藏并创建关联笔记。
5. 在“设置”展示自定义精灵称呼和个人 AI 接入；可导出 ZIP，再在独立测试安装中验证导入。正式个人数据不用于开发测试。

## 机器学习部分怎么解释

| 输入 | 模型计算 | 输出与后续处理 |
| --- | --- | --- |
| 用户主动选择的最多四张照片 | 已有多模态模型理解场景与可见内容 | 候选标签、照片描述和标题；用户确认后加入草稿 |
| 自然语言查询与手账文字 | 已有语言模型进行相关性判断和分批重排 | 已存在记录的 ID 与理由；不接受编造的记录 ID |
| 出游需求与本次联网检索的网页 | 搜索服务获取资料，语言模型按需求整理；程序核对来源 ID 及原文地点名 | 推荐地点、网页来源与待核对事项；可保存收藏 |

这是预训练模型的推理应用，没有自行训练基础模型。模型权重由使用者所接入的服务提供；SQLite、排版、关键词搜索与备份是普通软件功能。没有配置真实服务时，不能把本地关键词搜索或模拟响应称为真实模型推理。

## 实验部分

`experiments/` 保留 1.0 冻结的虚构教学数据和关键词/标签基线，目标答案不进入模型请求。它不再是应用的推荐目录，也不能作为 1.1 联网推荐效果。新版需要记录实际搜索时间、网页来源快照与独立相关性标注再测量；真实模型指标仍待测，不能把模拟响应称为准确率。

这套历史样例尚未经过独立人工复核。照片理解、联网搜索成功率、模型推荐、手机端耗时与界面体验需在个人服务和设备上分别测试；本轮证据见 [1.1 验证记录](验证记录-1.1.md)。地图交互、SQLite 和备份属于普通软件功能；模型对照片与网页资料的理解才是机器学习部分。
