# 旅页课程展示说明

项目题目建议：基于预训练多模态模型的智能旅行手账 Android 应用。

## 展示顺序

1. 打开“手账”，主动载入三篇教学示例，展示照片、地点、日期与文字排版。封面是程序生成的示意插画，正文是虚构样例。
2. 新建一篇自己的记录，选照片、输入标题与文字，保存后重新打开应用，展示本地持久保存。可以再编辑或保留草稿。
3. 在独立“搜索”页输入“看海”等文字，展示本地关键词搜索。配置 AI 后可展示使用不同说法寻找同一段经历的智能搜索。
4. 在“灵感”页输入需求，例如“想看海、节奏慢一点，两三天”，由已配置的模型解析需求并对资料库中的目的地排序。查看理由、资料来源与待核对条件，加入想去清单，再开始关联手账。
5. 在“设置”展示自定义精灵称呼和个人 AI 接入；可导出 ZIP，再在独立测试安装中验证导入。正式个人数据不用于开发测试。

## 机器学习部分怎么解释

| 输入 | 模型计算 | 输出与后续处理 |
| --- | --- | --- |
| 用户主动选择的最多四张照片 | 已有多模态模型理解场景与可见内容 | 候选标签、照片描述和标题；用户确认后加入草稿 |
| 自然语言查询与手账文字 | 已有语言模型进行相关性判断和分批重排 | 已存在记录的 ID 与理由；不接受编造的记录 ID |
| 出游需求与目的地资料 | 语言模型提取条件并排序；程序执行已知地区等筛选 | 推荐地点、理由与待核对事项；可保存收藏 |

这是预训练模型的推理应用，没有自行训练基础模型。模型权重由使用者所接入的服务提供；SQLite、排版、关键词搜索与备份是普通软件功能。没有配置真实服务时，不能把本地关键词搜索或模拟响应称为真实模型推理。

## 实验部分

`experiments/` 提供冻结的虚构教学数据和关键词/标签基线，模型与基线使用相同可见文本，目标答案不进入模型请求。已运行的基线数值、指标定义、限制和真实模型运行命令见 [实验说明](../experiments/README.md)。模型指标保留待测，不把样例基线当成模型准确率。

这套样例尚未经过独立人工标注复核。照片识别效果、真实服务成功率、手机端耗时和界面体验需要在用户的服务与设备上单独测试；当前测试证据见 [验证记录](验证记录.md)。目的地库只有三十项，不是实时旅游搜索，预算、天气、交通和开放信息需另行确认。
