- 台湾/香港/澳门的「区县」沿用 `china-cities.json` 里同尺寸单元。

## 缩放与层级参数（`ProvinceMapView`）

| 常量 | 值 | 含义 |
|---|---|---|
| `minZoom` | 1.0 | 全国层最小倍数（=铺满屏幕） |
| `maxZoom` | 9.0 | 最大放大倍数 |
| `countyMinZoom` | 0.6 | 省图层可继续缩小到的下限 |
| `returnZoom` | 0.68 | 省图层越过即退回全国 |
| `leaveMaxZoom` | 5.5 | 退回全国时的倍数上限（北京、澳门这类小省不会一步跳到细部） |
| `drillFillRatio` | 0.62 | 焦点省占屏达到 62% 时进入省图层 |

进入省：`zoom / fitZoom(省)`；退出省：`zoom * fitZoom(省)`（上限 5.5）；省→省：`zoom * fit(旧省) / fit(新省)`。只有「继续放大」才会触发下钻，缩小时不会被动吸回省图层。
