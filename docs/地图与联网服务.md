# 地图与联网资料

## 1.3 原生城市地图

首页为 Android View/Canvas 原生绘图，Compose 提供控制与底部卡片。地图不启动 WebView，不连接地图 SDK、在线瓦片或地图 Key。旧 `assets/map/`、Leaflet 许可证及网页测试仍保留供历史比较，当前入口为 `MapSurface.kt → NativeTravelMapView.kt`。

`app/src/main/assets/atlas/china-cities.json` 包含 34 个省级区域的外形、原始南海图形，以及 391 个地市级/省直辖行政单元。直辖市、香港、澳门作为独立城市；台湾地区采用 22 个县市边界。全国只展示浅色轮廓；用户去过的笔记按实际坐标点亮城市，未去记录显示旗帜。

杭州只填杭州，宁波等同省城市保持轮廓。最近更新的已去记录决定同城颜色或拼贴方式；城市内最多裁剪拼贴四张已去记录照片。删除最后一个已去足迹、或将其改为想去后恢复轮廓。未去计划、教学示例不自动点亮。

边界由 `scripts/prepare-city-atlas.py` 生成：DataV.GeoAtlas 的省/市素材用于课程学习，保留高德来源说明；台湾县市来自 [NLSC/MOI 开放数据](https://data.gov.tw/en/datasets/7442)（COUNTY_MOI_1140318，2025-03-18），采用 [plotdb/pdmaptw v2.4.0](https://github.com/plotdb/pdmaptw/releases/tag/v2.4.0) 的经纬度 GeoJSON 衍生文件，依 Open Government Data License 1.0 署名使用。固定台湾文件 SHA-256 为 `a809e483184d7762918476058cc9d7e10e9720113187afee2a04b4f7ced3103f`。每份素材的 URL、下载校验值、覆盖说明和最终文件校验值保存在 `atlas/SOURCES.json`。

素材生成会简化细小转折，保留多面、孔洞与岛屿；仅用于手账可视化。某些地区的默认标签点在海上，生成器会选择真实多边形内的定位点，并通过全部 391 个选择锚点的包含测试。边界缺失时不以省份冒充城市。绘图单元不用于限制 AI 推荐目的地。

旧记录没有坐标时仍不捏造位置；用户手动选点后才显示。覆盖以外可以保存坐标笔记和旗帜，界面说明暂无城市图块，不显示填城控件。地图不申请 GPS 权限，也不发送照片和正文给地图服务。

本机照片/透明插画的缩略副本在 IO 线程读取，保留透明通道并纠正 EXIF 方向。每批最多解码 64 张可见范围图片，同一视野更多时暂时回退纯色/普通标记，移动或放大后按新视野加载。Photos 模式缺图时回退所选纯色；原始照片不改动。插画仍可小尺寸显示、长按拖动并保存位置。

## 历史 1.2 网页地图（当前首页不使用）

- leaflet.css SHA-256（Base64）：`p4NxAoJBhIIN+hmNHrzRCf9tD/miZyoHS5obTRR9BMY=`。
- 两个文件从对应固定版本包下载后，已按上述官方发布校验值核对。

1.2 完整中国底图来自 [DataV.GeoAtlas 全国省级地理数据](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)，随应用提供 `china-boundaries.js`，不在运行时下载。包含 34 个省级区域和原始南海图形。原始文件 SHA-256：`99adfeded5223848bbe37a0a12f8023e11ee12161c7800521c27db42fdeac275`；封装后 JS SHA-256：`87e371ade0b4f2cf3d86efd03e8a693e841a5121acee4c14ae85193c0619f049`。坐标、属性与几何均保留，只增加 JS 赋值封装。

按 [阿里云官方工具说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)，该数据来自高德开放平台，用于学习交流。本项目为大学课程实验，地图界面保留高德/DataV 来源与学习用途标记，不将数据描述为自行创作或商用授权。

用户主动切换“街道底图”后，才使用 OpenStreetMap Standard HTTPS 瓦片。署名持续显示，应用发送 `TravelJournal/1.2.0` 和仓库链接，采用正常 HTTP 缓存，无批量预取或离线街道下载。连接失败时，完整中国地理底图仍然显示。规则见 [OSMF Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)。

默认中国视野只是起点，可自由移动到其他国家；没有预设地点选项或推荐库限制。点选得到 WGS84 经纬度，地点名称由用户填写，不申请 GPS 权限。旧笔记未标坐标时留空，不通过模糊名称自动捏造位置。

地图在系统 WebView 中运行，周围为原生 Compose 界面。白名单包含本地中国地图脚本，Android 侧资源测试直接核对其可读。外部脚本被阻止，署名链接由系统浏览器打开。JS 桥提供选点、笔记 ID、视野与插画拖动回调，校验数值和实际记录。

用户插画在本地照片目录保存；地图仅通过受控的本机 HTTPS 路径读取缩略副本，保留透明通道、纠正图片方向、限制解码尺寸并排除 EXIF。不允许地图加载远程插画 URL 或任意本机文件。插画、大小和位置随笔记与备份保存，恢复时重映射图片名；拖动不能重建已删除笔记。

根据用户后续要求，默认插画缩小，全国视野收起文字并限制图形尺寸，触控区域保留至少 48。地点增加“去过／未去过”；使用本地多边形包含判定找出有去过足迹的省级区域，将其提亮，其他区域保持暗色。状态改回未去过或删除最后一个去过足迹后，区域恢复暗色。旧普通旅行记录默认去过，教学示例和从想去清单开始的新计划默认未去过；状态写入备份。

## 联网推荐

推荐调用 [Tavily Search 官方接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)，先获取实际网页结果，再将摘要和出游需求交给使用者配置的 Chat Completions 模型整理。设置中必须分别填写模型密钥与 Tavily 搜索密钥，并确认发送说明。不能通过一句提示词让普通文本模型自动获得联网能力。

无内置目的地数据文件，没有国内省市白名单。搜索结果是每次请求的网页资料；程序只接收这些结果中的来源 ID，并要求候选名称出现在引用摘要或标题中，避免模型添加无来源地点。无法证明网页内容完全正确或建议充分满足条件，用户仍需检查来源与出行信息。失败或空结果不会用历史目录或模型记忆冒充搜索结果。

两种密钥使用独立随机 IV 通过 Android Keystore 加密。导出备份不包含任一密钥、IV 或设置。没有在开发中填写用户密钥或调用收费模型、搜索接口；协议和工作流使用模拟传输验证。

## 历史网页组件复查（不替代原生检查）

`scripts/test-map.cjs` 用 Playwright 对 390×720 与 1024×650 视口检查选点、同地多篇、标记数字、缩放、全球坐标、文本安全与底图失败提示。测试拦截所有公共瓦片请求并返回本地夹具，不通过机器人拖动消耗公共地图服务。

1.2 另有 `scripts/test-map-offline.cjs`：阻断所有外部请求，使用真实随包中国几何，检查 390×520、1024×650 两个视口的 34 省级图形、完整地图离线缩放、个人插画、拖动与街道失败时保留底图。默认和缩放阶段外部请求数为 0；切换街道后的请求被拦截为失败，未发送至公共服务。演示插画为测试脚本绘制，截图不能当作用户旅行证据。

可在安装 Node/Playwright 后，先用 Python 启动应用地图资源的本地 HTTP 服务，再执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory app/src/main/assets/map
# 在另一个终端安装固定测试依赖（不参与 Android 构建）：
npm install --prefix .tools/browser --no-audit --no-fund playwright@1.58.2
NODE_PATH="$PWD/.tools/browser/node_modules" node scripts/test-map.cjs
```

需要已安装的 Chromium；可用 `MAP_TEST_BROWSER` 指定浏览器可执行文件。测试输出位于 `.tools/map-qa/`。夹具截图只验证网页组件，不能称作 Android 整机截图或真实地图服务验收。
