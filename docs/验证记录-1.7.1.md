### 为什么是「千问」而不是「千问 + 通义」

通义 App 已于 2025-11 更名「千问」，域名迁到 `qianwen.com`，继续保留 `tongyi` 只会指向旧地址。所以本次是**替换**而非并存。

### 为什么只改一个列表就够

`AiWebHelper.services` 是唯一数据源：

- `NativeInspirationScreen.kt` 用 `AiWebHelper.services.forEach { FilterChip(...) }` 渲染选择项（`FlowRow`，5 个自动换行）；
- 按钮文案与成功/失败提示都走 `serviceLabel(id)`；
- 打开网页走 `serviceUrl(id)`。

因此 UI、跳转、文案全部自动跟随，没有第二处硬编码。

### 兼容性

- `aiService` 状态只在 `rememberSaveable` 里，**不落盘**，所以删除 `tongyi` 不会让老用户遇到「记住了一个已不存在的服务」；
- `serviceLabel(id)` / `serviceUrl(id)` 对未知 id 回退到列表第一项（Kimi），不会崩。
