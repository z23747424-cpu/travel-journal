# 旅行计划与地图标记的设计延续核对

本轮是既有设计的功能扩展。根 `DESIGN.md` 与 `.impeccable/design.json` 保留，不重建或替换视觉系统。

- 配色：继续使用 `--paper: #f7f3ea`、`--ink: #304532`、`--green: #4c6b52`，配合原有纸纹和边角远山。
