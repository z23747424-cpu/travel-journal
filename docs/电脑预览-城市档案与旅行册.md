# 城市档案、照片快记与旅行册

2026-11-07。依据用户确认的「城市档案＋轻量记录＋旅行册」方向，落实到本地电脑交互预览。沿用纸色与鼠尾草绿的简洁杂志风，首页继续以地图为主体。Android 工程、APK 和 GitHub 发布不属于本轮改动。

## 使用路径

1. 首页点击省份，省内展开城市，周围省份虚化。点击城市进入城市档案，查看封面、统计和回忆摘要。
2. 点击「留下一程」或长按地图，选择照片、写一句话、确认地点与日期。可直接保存，也可展开补充标题、标签、旅行册与照片版式。
3. 在城市档案选择「装饰这座城」，单独设计颜色或照片拼贴。选中拼贴照片后调整水平位置、垂直位置和放大倍数，预览真实城市轮廓中的取景；选择其中一张作为城市封面。
4. 顶部书本打开旅行册。可以创建旅行册、撰写序言，并把多座城市的手账按日期串联；无须先建册才能记录。移除册只解除归属，不删除记录和城市装饰。
5. 点击想去旗打开该城市档案，选择「开始这段旅行」，保存后同一条记录成为足迹。原心愿日期、标题和文字独立保留在完整手账里。

## 数据与兼容

浏览器 IndexedDB `lvye-desktop-preview` 升至版本 2，使用 `records`、`trips`、`cityStyles` 三个对象存储。城市装饰按城市代码独立保存，第一次记录初始化，之后写笔记不再改变它。旧版记录自动迁移，原照片拼贴和颜色作为初始样式保留。

记录添加 `tripId`、`layout`、`tags` 与可选 `wish`。旅行册包括名称与序言；城市装饰包括色值、照片、照片宽高比、每张照片的取景参数与封面序号。照片在浏览器内压缩至最长边 1200 像素，不改电脑原文件、不上传服务器。

JSON v2 导出三个存储，支持 v1 记录文件导入。导入先校验日期、图片、坐标、样式与关联，再以一个事务写入；相同编号更新前提示。数据库升级、转换想去、编辑示例与删除旅行册均保留既有个人内容。地图边界仍为应用内同一份 391 个市级或独立行政单元素材。

## 验证入口

- `scripts/test-desktop-preview.cjs`：全国/省份/城市、邻省虚化、缩放平移、长按、示例保留、手机/平板/窄屏、自动刷新。
- `scripts/test-desktop-journal.cjs`：照片快记、城市档案、独立封面与取景、照片阅读、跨城市时间轴、心愿转换、标签/旅行册搜索、JSON 往返与非法文件、v1 数据库升级、v1 导入、移除旅行册保留记录。
- 浏览器测试使用隔离上下文，不读写用户日常浏览器资料。截图与机器检查结果保存在被 Git 忽略的 `.tools/desktop-preview-qa/`。

上述是桌面 Chromium 交互验证，不能代替 Android 原生界面和真机验证。本轮不调用 AI；后续由分工中的 AI 模块对接现有记录。
