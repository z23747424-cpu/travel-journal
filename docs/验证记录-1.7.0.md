### 2. 「用它开始写计划」不可点的根因与修复

根因：按钮原先写的是 `enabled = draft == null`。只要用户**曾经打开过计划编辑器并「返回并保留草稿」**，本机就存在草稿，按钮会永久变灰且界面上没有任何解释；即使绕过禁用，`start()` 也会直接报「请先继续并保存未完成的草稿」，看起来就像点了没反应。

修复：

1. 按钮改为实心 `Button`，**永远可点**；
2. 有草稿时点击弹出对话框：「还有一份没保存的草稿」→「继续那份草稿」/「放弃草稿并新建」/ 点外部取消；
3. 卡片上常驻小字提示：有草稿时说明点开后可继续或新建；
4. 「自己写计划」「我的计划」里打开其它计划走的是同一个 `start()`，因此同样受益，不会再出现「悄悄失败」。

### 3. 计划编辑页自动填省份

- 新增 `CityAtlas.provinceCodeFor(vararg hints)`：按「省名/简称完全匹配 → 文字里出现省名或完整城市名 → 城市名以文字开头」打分，取最高分；海外或无法识别时返回 `null`（仍是「不关联」）。
- 新增 `PopularCountyProvinces.kt`：阳朔、婺源、宏村、乌镇、稻城亚丁、敦煌、香格里拉等 50 余个**县级/景区级**热门目的地的省份映射（地级市索引里没有这些名字）。
- 「用它开始写计划」时用 `planFromDestination()` 直接带上 `provinceCode`；
- 手动输入目的地的场景，由 `NativePlanEditor` 的 `LaunchedEffect(plan.destination)` 兜底识别；用户手动选过省份（含选「不关联」）后用 `provinceTouched` 锁定，不再自动覆盖。

测试：新增 `ProvinceLookupTest`（Robolectric，加载真实图集），覆盖城市 / 省名 / 简称 / 县级景区 / 海外 / 噪音文本，共 8 个用例（2 个 SDK 配置各跑一遍）。

### 4. 字体局部统一

根因：手写字体 `scrapbook_handwriting.ttf` 原来只有 **511 个字形**，界面里的 **279 个汉字缺字**（包括「陪」「设」「置」），缺字处回退系统黑体，所以「陪你记录的精灵」里「陪」明显不一样。

处理：

- 用 SIL OFL 授权的 Ma Shan Zheng 原字体，子集化为 **GB2312 全集 + 应用内全部字符 + 图集城市名 + 拉丁/标点**，替换 `res/font/scrapbook_handwriting.ttf`（5,775,828 B，APK 内压缩后 3,767,910 B）；
- 新增 `assets/licenses/MaShanZheng-OFL.txt`，设置页「开源许可」弹窗同时展示图标与字体许可（标题改为「开源许可」）；
- 复查：应用源码里的 783 个汉字仅剩「甪」1 个不在字体中（「甪直」这类极冷僻地名，回退属正常）；
- 顺带统一醒目栏目字号：设置页「当前主题」、灵感页「AI 网页版推荐」、手账页「照片笔记 / 旅途照片」由 `titleMedium`（系统字体）改为 `titleLarge`（手写体），与其它大标题一致。全局 `bodyMedium` 等正文仍用系统字体，未做全局替换。
